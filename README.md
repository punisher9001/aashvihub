Quick-commerce & Doctor-Curated Wellness Store with all-India delivery.

## Key Highlights & Improvements
- **Owner & Verified Support**: Prominently features Dr Mukul Kumar with direct call support (+91 8988227729) and instant 1-click WhatsApp order integration.
- **Resilient Dual-Engine Database**: Automatically connects to MySQL when available. If MySQL is not installed or the database is not created, it seamlessly uses the embedded persistent storage (`database/local_store.json`), preventing crashes on any machine.
- **Premium Quick-Commerce Experience**: Blinkit/Zepto-style sticky blurred navbar, interactive categories, real-time search, smooth quantity stepper (`[-] [qty] [+]`), product details modal with doctor's notes, slide-out cart drawer with free delivery progress meter, and customer order tracking.
- **Order Tracking**: Customers can enter their Order ID or Phone number to track live order dispatch stages.
- **Multi-lingual Support**: English, Hindi, Urdu, Marathi, Punjabi, Malayalam, Telugu, Tamil, Bengali, Gujarati, Kannada, Odia.

## Quick Start
1. Ensure Node.js 18+ is installed.
2. Install dependencies (if not already done):
   `npm install`
3. Run the application:
   `npm start`
4. Open your browser:
   - **Customer Storefront**: `http://localhost:3000`
   - **Admin Management Portal**: `http://localhost:3000/admin.html` (Default: `admin` / `admin123`)
